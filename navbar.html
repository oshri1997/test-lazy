Responsive Navbar Component

This is a responsive navigation bar that adapts to different screen sizes. On desktop, all navigation links are visible. On mobile devices (screens smaller than 768px), a hamburger menu appears that toggles the navigation links.

Features:

  • Fully responsive design for mobile and desktop
  • Hamburger menu with smooth animations
  • Semantic HTML structure
  • Clean CSS styling with hover effects
  • No external dependencies - vanilla HTML and CSS
  • Smooth transitions and animations
  • Sticky navbar that stays at top while scrolling

Try resizing your browser window to see the responsive behavior!
